# خطة: شاشة اختيار البرنامج، والتابات، والجلسات، وشكل جديد

> **الحالة:** مقترح (2026-11-06)، ومستني موافقة المالك. القرار في [ADR-0006](ADR/0006-workspace-tabs-sessions.md).

## المطلوب (قرارات المالك، 2026-11-06)

1. **`mirah` لوحده** يفتح **شاشة اختيار**: مرآة بتدوّر على البرامج المتسطّبة عندك، وانت تختار منها.
2. **التابات جوه الشريط اللي فوق:** تفتح تاب جديد جنب اللي شغال من غير ما تخرج.
3. **التسجيلات والـ logs** تبقى في مكان منظم، مش جنب البرنامج. **وكل جلسة ليها ID** تقدر تكمّلها بعدين.
4. **"سجّل كل جلسة"** يبقى إعداد في القايمة، بدل `--record`.
5. **الشكل:** الشريط والقايمة لازم يتحسّنوا كتير. والكلام جوه البرنامج كمان، والمالك هيبعت screenshot ليه.

## 1. شاشة اختيار البرنامج

```
                    ╭──────────────────────────────────────╮
                    │            تفتح أنهي برنامج؟  ◆ مرآة │
                    ├──────────────────────────────────────┤
                    │▌            Claude Code    claude  ◉ │
                    │                OpenCode  opencode  ○ │
                    │               Codex CLI     codex  ○ │
                    │              Gemini CLI    gemini  ○ │
                    │              PowerShell     shell  ○ │
                    ├──────────────────────────────────────┤
                    │  ↑↓ اختار · Enter افتح · Esc خروج   │
                    ╰──────────────────────────────────────╯
```

- **البرامج اللي مرآة بتدوّر عليها:** `claude`، و`opencode`، و`codex`، و`gemini`، و`qwen`، و`aider`، و`crush`، و`cursor-agent`، و`amp`، و`copilot`، و`goose`. وفي الآخر الـ shell بتاعك.
  - التدوير بيبقى في الـ PATH بنفس الطريقة اللي بنشغّل بيها البرامج على ويندوز (`.cmd` و`.exe`).
  - والبرنامج اللي مش موجود مابيظهرش.
- **آخر برنامج استخدمته** بيبقى هو المختار.
- **`mirah claude`** بيشتغل زي ما هو، ومن غير الشاشة دي.
- **في `config.toml`:** تقدر تضيف برنامج مش في القايمة (`[[agents]] name = "..."  command = "..."`).

## 2. التابات

```
 ✕  ⚙  ●   ┃ + ┃ opencode ┃▐ claude ▌┃                                    ◆ مرآة
```

- **التاب المفتوح بيتعلّم.** وكل تاب بيفضل شغال في الخلفية، وبيكمّل يقرا output البرنامج بتاعه، بس مابيترسمش.
- **تاب فيه حاجة جديدة وانت مش عليه** بيظهر عليه `•`.
- **التحكم:**

  | الاختصار | بيعمل إيه |
  |---|---|
  | `Ctrl+]` وبعدين `←` أو `→` | تاب جنبه |
  | `Ctrl+]` وبعدين رقم من 1 لـ 9 | التاب رقم كذا |
  | `Ctrl+]` وبعدين `t`، أو الضغط على `+` | تاب جديد: بتفتح شاشة الاختيار |
  | الضغط على اسم التاب | بيروح له |
  | `✕` | بيقفل التاب اللي انت عليه (بعد تأكيد). ولما يتقفل آخر تاب، مرآة بتخرج |

- **الـ resize** بيوصل لكل التابات.
- **لو التابات كتير:** أسماؤها بتتقصّر الأول، وبعدين بيظهر `‹ 3 ›`.

## 3. الجلسات والتخزين

- **كل تاب = جلسة**، وليها ID قصير ومقروء، زي `0611-0457-k3f2` (الشهر واليوم، والساعة والدقيقة، و4 حروف).
- **المكان:** `%LOCALAPPDATA%\mirah\sessions\<id>\` (و`~/.local/state/mirah/sessions/<id>/` على الباقي):
  - `session.toml`: البرنامج، والأمر، والفولدر اللي اشتغل فيه، وإمتى بدأ وإمتى خلص.
  - `output.vt`: التسجيل، لو التسجيل شغال.
  - `mirah.log`: الـ log الخاص بالجلسة دي.
- **أوامر جديدة:**
  - `mirah sessions`: بيعرض آخر الجلسات (الـ ID، والبرنامج، والفولدر، والوقت، والحجم).
  - `mirah resume <id>`: بيكمّل جلسة (شوف السؤال تحت).
  - `mirah sessions --open`: بيفتح فولدر الجلسات.
- **التنضيف:** بيفضل آخر 50 جلسة أو آخر 14 يوم، أيهم أكتر. وده بيتغيّر من `config.toml`.
- **`--record`** بيفضل للتوافق مع القديم، بس بيكتب في نفس المكان، وبيطبع الـ ID.
- **إعداد "سجّل كل جلسة"** في القايمة، ومقفول افتراضياً.

## 4. الشكل الجديد

- **ألوان أهدى ومتناسقة مع خلفيات Claude وopencode الغامقة:**
  - الشريط بخلفية أفتح شوية من خلفية البرنامج.
  - والتاب المفتوح بخلفية زي البرنامج، كأنه "متصل" بيه.
  - ولون واحد مميز (accent) للحاجة المختارة بس.
- **فواصل `┃` رفيعة** بين أجزاء الشريط، والأيقونات من غير كلام لما المساحة ضيقة.
- **القايمة والتأكيد بقوا صندوق** بحواف مدوّرة (`╭╮╰╯`)، فيه عنوان، والسطر المختار عليه علامة `▌`.
  - القيم بتتعرض كاختيارات جنب بعض، والمختار عليه لون.
- **شاشة الاختيار** في نص الشاشة وبنفس الشكل.
- **قبل التنفيذ:** صفحة معاينة فيها الشكلين، القديم والجديد، والمالك يختار.

## التنفيذ (مراحل)

| المرحلة | فيها إيه |
|---|---|
| **W1 الجلسات** | `Session` بقى مستقل (pty، وemulator، وrecorder، وkiller، وmouse)، و`Workspace` فيه أكتر من جلسة، والتوجيه للتاب المفتوح |
| **W2 الشاشة والتابات في الشريط** | الشريط الجديد بالتابات، والاختصارات، والضغط بالماوس |
| **W3 شاشة الاختيار** | التدوير على البرامج، والشاشة، وآخر برنامج، و`[[agents]]` |
| **W4 التخزين** | `sessions/<id>/`، و`session.toml`، و`mirah sessions`، و`resume`، والتنضيف، وإعداد "سجّل كل جلسة" |
| **W5 الشكل** | الألوان، والصناديق، والفواصل، وsnapshots |

- **الإصدار:** `0.3.0-alpha.1`.

## المخاطر

- 🚨 **أكتر من برنامج شغالين مع بعض** معناه pty لكل واحد، وكل التابات بتقرا output طول الوقت. الأداء لازم يتقاس بـ 3 تابات.
- ⚠️ **"تكمّل الجلسة"** بيعتمد على كل برنامج: كل واحد ليه طريقته (`claude --continue`، و`opencode --continue`، و`codex resume`). ولازم يتأكد لكل برنامج.
- ⚠️ **مرآة في الوقت ده بقت قريبة من tmux.** لازم نفضل مركّزين على العربي، ومانزوّدش حاجات زي تقسيم الشاشة دلوقتي.
