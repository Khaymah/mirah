06 · المعمارية

الأداة بتشتغل إزاي من جوه

الأداة بتعمل نسختين من الشاشة. النسخة المنطقية هي اللي الـ agent كتبها بالظبط، والمؤشر والماوس والنسخ كلهم بيشتغلوا عليها. النسخة المرئية هي اللي بتترسم على الترمنال. والـ Cell Map بيربط كل خلية في النسختين ببعض.

flowchart LR
  U["المستخدم"] --> IN["Input Mapper"]
  IN --> PTY["PTY Host"]
  PTY <--> APP["claude · codex · gemini"]
  PTY --> VT["VT Parser + Grid"]
  VT --> SEG["Run Segmenter"]
  SEG --> BIDI["Bidi + Shaper"]
  BIDI --> MAP["Cell Map"]
  MAP --> R["Diff Renderer"]
  R --> T["الترمنال الحقيقي"]
  MAP --> IN
  MAP --> CP["Copy Mode · OSC 52"]
  PROBE["Capability Probe"] --> R

  2. مسافتين أو أكتر ورا بعض بيفصلوا بين الأعمدة.
  3. لو الخلفية أو الـ inverse اتغيّروا، ده عنصر واجهة تاني فبيتفصل.

  5. الجزء اللي مفيهوش حروف RTL بيعدّي من غير أي حساب، وده أغلب الشاشة.
  6. عرض الجزء بيفضل ثابت. لو "لا" قصّرته خلية، بنحشي مسافة.

ليه Rust

اللغة الوحيدة اللي فيها binary واحد ومكتبة VT ناضجة (alacritty_terminal) ومكتبة bidi كاملة (unicode-bidi) في نفس الوقت. وده كمان اللي بيميّزها عن agent-rtl المبنية على Node. Go مكتبة الـ bidi بتاعتها ناقصة، وBun محتاج runtime.

برا نطاق v1

Windows/ConPTY، تحريك الأسهم بالترتيب المرئي، الـ selection العادي بالماوس (البديل copy mode)، والترمنالات اللي بتعمل bidi ومش بتدعم BDSM.

09 · الخلاصة

نبنيها؟

أيوه، بس كمشروع open source بيبني سمعة، مش كبيزنس. الوجع حقيقي، والشركات مش هتحلّه قريب، وBDSM بيخلي الحل ممكن دلوقتي. بس الجمهور صغير، و agent-rtl سبقتنا بالفكرة.

علشان كده أول أسبوعين مقابلات وspike بـ Rust بس. لو البوابة عدّت، نبني binary في Rust يتميّز بالحاجات اللي محدش عملها: المؤشر صح، النسخ بالنص الأصلي، التفاوض على BDSM، والـ corpus المفتوح. ولو ماعدّتش، نساهم في agent-rtl أو ننشر الـ corpus لوحده.
